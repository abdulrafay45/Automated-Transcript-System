## 📌 Project Overview
The **Automated Transcript System** is a professional-grade web application developed specifically for the National University of Modern Languages (NUML). It revolutionizes academic record management for BS programs by replacing manual evaluations with an automated, secure, and fault-tolerant digital framework.

## 🚀 Key Features
* **Student Portal:** Real-time access to unofficial transcripts, result cards, and course schedules.
* **Administrative Control:** Streamlined record management for coordinators and result processing for exam staff.
* **Automated Generation:** Efficient creation of Official/Unofficial transcripts and Detailed Marks Certificates (DMCs).
* **High Availability:** Designed with fault tolerance and scalability to handle university-wide academic data.

## 🧬 Engineering Methodology
This system was developed using a **Waterfall Iterative Approach**, ensuring that each phase—from requirement engineering to deployment—was structured and systematic.

### Quality Assurance (QA)
To ensure performance meets stringent academic expectations, we implemented:
* **Black Box Testing:** Validating system outputs against functional requirements.
* **Automated Functional Testing:** Leveraged Selenium to validate the integrity of Official Transcript generation and Results Management.
